# 📚 Estudos — Desenvolvimento Web

Este repositório foi criado com o objetivo de **revisar, praticar e consolidar meus conhecimentos em desenvolvimento web**.

Aqui vou reunir anotações, exercícios, pequenos projetos, experimentos e exemplos práticos relacionados às tecnologias que já estudei ou que estou aprendendo.

A ideia é utilizar este espaço como um **laboratório pessoal de estudos**, revisitando conceitos importantes e aprofundando meu conhecimento através da prática.

---

## 🎯 Objetivos

- 📖 Revisar os fundamentos do desenvolvimento web
- 💻 Reforçar conceitos que já aprendi
- 🧠 Identificar e corrigir lacunas no meu conhecimento

- 🚀 Criar pequenos projetos
