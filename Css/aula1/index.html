Anatomia do CSS

* Declaration: é a propriedade que você quer alterar, por exemplo: color, font-size, background-color, etc.

* Selector: é o elemento que você quer alterar, por exemplo: h1, p, div, etc.

* {} - context: é o delimitador que indica o início e o fim da declaração.

* Property Value: é o valor que você quer atribuir à propriedade, por exemplo: red, 16px, #000, etc.

* Properties: são as características que você quer alterar, por exemplo: color, font-size, background-color, etc.

* a dieferença entre declaration e properties é que a declaration é a propriedade que você quer alterar, enquanto a properties são as características que você quer alterar.
