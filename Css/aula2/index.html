Especificidade do CSS

* Especificidade: é a forma como o navegador decide qual regra de estilo aplicar a um elemento quando há várias regras conflitantes.

* Selector: é o elemento que você quer alterar, por exemplo: h1, p, div, etc.

* {} - context: é o delimitador que indica o início e o fim da declaração.

* Property Value: é o valor que você quer atribuir à propriedade, por exemplo: red, 16px, #000, etc.

* Properties: são as características que você quer alterar, por exemplo: color, font-size, background-color, etc.

* A diferença entre especificidade e propriedades é que a especificidade é a forma como o navegador decide qual regra de estilo aplicar a um elemento quando há várias regras conflitantes, enquanto as propriedades são as características que você quer alterar.
